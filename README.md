# Limetax Dashboard

A small React/Vite app for scoring and summarizing companies for the Limetax case study.

## Start

```sh
npm install
npm run dev
```

## .env

Create a `.env` file in the project root:

```sh
VITE_OPENROUTER_API_KEY=your_openrouter_api_key
VITE_OPENROUTER_MODEL=your_openrouter_model
```
